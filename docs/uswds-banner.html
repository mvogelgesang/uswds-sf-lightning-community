Class: uswds-banner

uswds-banner()

new uswds-banner()

A Lightning Web Component (LWC) for displaying a USWDS (* States Web Design System) banner. The banner includes header text, action buttons, and secure connection indicators. It supports both civilian and military banner types and allows toggling the banner content visibility.
